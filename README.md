# 灵动音符 - 拟物风黑胶音乐播放器页面

一个基于 **HTML5** 和 **CSS3** 构建的现代网页音乐播放器界面。项目采用极简、暗黑的设计风格，完美模拟了传统黑胶唱片机（Vinyl Record）的拟物化视觉效果，并配备了优雅的歌词展示面板与原生音频控制。

## 🌟 项目亮点与特性

* **拟物化黑胶唱片视觉**：通过 CSS3 `@keyframes` 实现唱片持续旋转动画（`rotateDisc`），并通过绝对定位复现了唱针与唱片的空间层次感。
* **现代暗黑美学**：使用深色背景（`#121212`）搭配高质感的渐变色背景（`linear-gradient`），辅以毛玻璃效果（`backdrop-filter`）的底部控制栏。
* **优雅的歌词遮罩**：利用 CSS 蒙版技术（`mask-image` / `-webkit-mask-image`）为歌词面板的顶部和底部添加了渐变淡出效果，使滚动体验更加自然平滑。
* **无 JS 依赖**：纯 HTML/CSS 架构，音频播放完全基于浏览器原生的 `<audio>` 控件。
* **原生控件视觉重塑**：通过 CSS 高级滤镜（`filter: invert(1) hue-rotate(180deg)...`）将原本单调的浏览器自带音频条重塑为契合暗黑主题的科技感外观。
* **精致的交互反馈**：唱片悬浮微放大、按钮悬浮上浮（`translateY`）并伴随阴影扩散，带来丝滑的动效反馈。
